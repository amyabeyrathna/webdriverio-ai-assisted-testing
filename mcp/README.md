# MCP integration

This folder is reserved for a Model Context Protocol server that can expose
approved testing tools to an MCP-compatible IDE assistant.

Suggested first tools:
1. Open the configured test application.
2. Run a named test or test suite.
3. Read the latest test summary.

Keep tool permissions narrow. Do not expose arbitrary shell execution or
secrets to the model. The MCP server has not yet been implemented in this starter.
