# WebdriverIO AI-Assisted Testing

A JavaScript-based WebdriverIO starter framework using pnpm, Allure reporting, and GitHub Actions.

## Technology
- Node.js 22
- pnpm 10
- WebdriverIO 9
- JavaScript (ES modules)
- Mocha
- Allure Reporter
- GitHub Actions

## Prerequisites
Install Node.js 22 and pnpm 10.

## Setup
```bash
pnpm install
pnpm test
```

The sample UI test uses the public SauceDemo demo application.

## Allure report
```bash
pnpm allure:generate
pnpm allure:open
```

Or run `pnpm allure:serve` to generate and serve the results.

## GitHub Actions
- `ci.yml`: runs UI tests on pushes and pull requests to `main`, then uploads Allure results/report as an artifact.
- `regression.yml`: supports manual execution and a weekday scheduled run.

Download the `allure-report-*` artifact from the GitHub Actions run to view the HTML report locally.

## AI and MCP
The `ai/` and `mcp/` folders contain safe starter placeholders and design notes. No LLM provider or MCP server is connected yet. Add a provider only after deciding which service to use, validating model output, and configuring secrets securely.

## Important
`pnpm-lock.yaml` is generated by `pnpm install`. Commit the generated lockfile after the first successful install so CI can use `--frozen-lockfile`.
